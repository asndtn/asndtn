### Projects

#### [Digital Wallet](https://github.com/asndtn/DigitalWallet)
* **Description:** Backend-oriented personal finance management web application designed for tracking multi-currency wallets, transactions, and custom categories.
* **Architecture & Features:** Utilizes Doctrine ORM entity mappings for database relations, handles multi-currency balance calculations, and implements transaction classification by categories and tags. Database schema managed via Doctrine Migrations, with static analysis verified by Psalm
* **Tech Stack:** PHP, Symfony, Doctrine ORM, PostgreSQL/MySQL, Twig, Bootstrap.

#### [Art Catalog & Management System](https://github.com/asndtn/ArtCatalog)
* **Description:** A Symfony web application developed as a Bachelor's degree thesis project, designed for structured cataloguing of artworks, artists, movements, and dynamic custom fields.
* **Architecture & Features:** Implements a full MVC structure with modular controllers for entities, secure administrative workflows, role-based access control, and dynamic form inputs. Seed data handled via DoctrineFixturesBundle.
* **Tech Stack:** PHP, Symfony, Doctrine ORM, PostgreSQL, Twig, Bootstrap, Psalm, PHP CS Fixer.
